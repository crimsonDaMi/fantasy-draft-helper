This repository's authoritative coding rules are in:

- [`.github/copilot-instructions.md`](.github/copilot-instructions.md)
- [`docs/CODING_AGENT_GUIDE.md`](docs/CODING_AGENT_GUIDE.md)

Read all five before making changes.

The MVP is complete (see `docs/MVP_COMPLETION_PLAN.md`'s Definition of Done
and Final Verification Record) — that document is now a historical record of
the original build, not a current scope boundary. Current scope, priorities,
and what's explicitly in or out for the next round of work live in
`DEVELOPMENT_PLAN.md`. Keep changes within `DEVELOPMENT_PLAN.md`'s agreed
scope and phase ordering unless the user explicitly expands it. `RELEASING.md`
governs versioning and image publishing for anything that ships.
